# 📇 ContactHub

A modern Personal Contact Management System that helps users securely manage their contacts with features like authentication, profile management, contact organization, image uploads, favorites, groups, dashboard analytics, and contact export functionality.

---

# 🚀 Features

## 👤 User Authentication
- User Registration
- Secure Login
- JWT Authentication
- Password Hashing using bcrypt
- Protected Routes

## 📞 Contact Management
- Add New Contact
- View All Contacts
- Edit Contact
- Delete Contact
- Contact Image Upload
- Favorite Contacts
- Search Contacts

## 📂 Organization
- Group Management
- Company-wise Contact Organization
- Dashboard Statistics
- Recent Contacts

## 👤 User Profile
- Update Profile Information
- Upload Profile Picture
- Settings Page

## 📤 Export
- Export Contacts to CSV

## ☁️ Cloud Storage
- Cloudinary Integration for Profile & Contact Images

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/contacthub.git
```

## Install Dependencies

```bash
cd backend
npm install
```

## Start Server

```bash
npm start
```
